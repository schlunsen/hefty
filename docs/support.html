Getting Started

Hefty is a disk usage analyzer for macOS that helps you find the largest files on your Mac. To get started:

  • Launch the app and click "Choose a Folder to Scan" or use one of the quick scan shortcuts (Home, Downloads, Documents, Desktop, or Macintosh HD).
  • Hefty will scan the selected folder and display the largest files in a treemap view and a sortable file list.
  • Click any file to select it, use Reveal in Finder to locate it, or delete files directly from the app.

Frequently Asked Questions

How do I scan a folder?

Click the "Choose a Folder to Scan" button on the welcome screen, or use one of the quick scan shortcuts (Home, Downloads, Documents, Desktop, Macintosh HD). You can also drag and drop any folder onto the app window.

Can I delete files from within the app?

Yes. Select a file and click the trash icon, or press the Delete key. You can also select multiple files using Cmd+Click or the Space bar, then delete them all at once. A confirmation dialog will appear before any files are permanently removed.

Is my data sent anywhere?

No. Hefty operates entirely on your local device. It makes no network requests and collects no data. See our Privacy Policy for details.

Why does Hefty ask for access to my Music library?

When scanning folders that contain your Music library, macOS requires permission to access those files. Hefty only uses this access to calculate file sizes and display disk usage — it never reads, modifies, or transmits the contents of your music files.

The app isn't showing any files after scanning.

This usually means there are no files above the minimum size threshold in the selected folder. Try scanning a different folder, or go to Settings and lower the default minimum file size.

How do I change the scan settings?

Go to Hefty → Settings (or press ⌘,) to adjust the default minimum file size, maximum number of files to display, and other preferences.

Keyboard Shortcuts

  • ↑ ↓ — Navigate file list
  • Space — Select/deselect file for batch operations
  • ⌘+Click — Toggle file selection
  • ⌘+A — Select all files
  • Delete / Backspace — Delete selected file(s)
  • Return — Reveal selected file in Finder
  • ⌘, — Open Settings
